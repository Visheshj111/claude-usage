# Claude Usage Tracker

Claude Usage Tracker is a Chrome extension that helps you keep track of your Claude usage and export your chats when you need them.

It is built for people who want a simple way to understand their activity without digging around manually.

## What this extension does

Track usage: Monitor your Claude usage in a practical way.  
Export chats: Save your conversations for backup, review, or analysis.  
On-screen UI support: Built to support in-screen interface workflows.

## Tech stack

Frontend: HTML, CSS  
Backend: TypeScript, JavaScript

## Project structure

Backend files: `src/backend`.
Note: Some backend-related logic also exists in other folders, but it is scoped to those sections.

UI files: `.html` and `.css` files across the project

## Current focus

In-screen UI support: This is an active area right now and improvements are ongoing.

## Why this project exists

The goal is to make Claude usage tracking and chat exporting feel straightforward, fast, and reliable.
